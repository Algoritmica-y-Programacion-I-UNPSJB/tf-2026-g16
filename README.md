## Reglas y alcance
Propuesta presentada por el grupo, pendiente de aprobación formal:

El juego será de un jugador contra la computadora.

Las palabras se seleccionarán aleatoriamente de un conjunto organizado por categorías, almacenadas en diferentes archivos.

El jugador contará con un máximo de seis intentos para adivinar la palabra, correspondientes a las seis etapas necesarias para completar el dibujo del ahorcado.

El puntaje se calculará en función del resultado obtenido en cada partida, según los criterios establecidos por el grupo.

Se implementará un sistema de ranking que almacenará los resultados en un archivo binario y conservará los cinco mejores puntajes.

La interfaz gráfica se desarrollará utilizando ChatGPT como herramienta de asistencia para la generación del código gráfico y la biblioteca SDL3.

El programa contará con un menú principal desde el cual el jugador podrá iniciar una partida o salir del juego. Durante la partida, podrá ingresar letras para intentar adivinar la palabra o abandonarla voluntariamente. Al finalizar cada partida, se mostrará el resultado correspondiente y se permitirá regresar al menú principal.
